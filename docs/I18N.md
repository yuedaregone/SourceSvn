# 多语言设计 (i18n)

本文档定义 SourceSvn 的多语言架构。MVP 阶段仅实现界面文本的国际化，后续可扩展动态语言切换。

## 设计目标

- 支持界面文本（菜单、按钮、提示、对话框）的多语言
- 支持运行时动态切换语言（不重启应用）
- 预留后续翻译 SVN 命令输出、AI 生成内容的可能性

## 支持的语言

MVP 阶段支持：
- **zh-CN**：简体中文（默认）
- **en-US**：英语

后续可扩展：zh-TW, ja, ko, de, fr 等。

## 目录结构

```
src/
├── locales/                    # 语言文件目录
│   ├── index.ts               # 导出语言包和配置
│   ├── zh-CN.json             # 简体中文
│   ├── en-US.json             # 英语
│   └── types.ts               # 类型定义（从 JSON 推导）
├── i18n/                      # i18n 工具模块
│   ├── index.ts               # Vue 插件初始化
│   ├── useI18n.ts             # 组合式函数
│   └── languageStore.ts       # Pinia store（语言状态）
└── ...
```

## 实现方案

### 1. 前端 i18n 工具 (Vue 3)

使用 `vue-i18n` 库：

```typescript
// src/i18n/index.ts
import { createI18n } from 'vue-i18n';
import zhCN from '../locales/zh-CN.json';
import enUS from '../locales/en-US.json';

export const i18n = createI18n({
  legacy: false,        // 使用 Composition API
  locale: 'zh-CN',      // 默认语言，从配置读取
  fallbackLocale: 'en-US',
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS,
  },
});
```

### 2. 语言切换 Store

```typescript
// src/stores/languageStore.ts
import { defineStore } from 'pinia';
import { i18n } from '@/i18n';

export const useLanguageStore = defineStore('language', {
  state: () => ({
    currentLocale: 'zh-CN',
  }),
  actions: {
    setLocale(locale: string) {
      i18n.global.locale.value = locale;
      this.currentLocale = locale;
      // 保存到配置
      useConfigStore().saveConfigPartial({ language: locale });
    },
    loadFromConfig() {
      const config = useConfigStore().config;
      if (config?.language) {
        this.setLocale(config.language);
      }
    },
  },
});
```

### 3. 配置扩展

在 `AppConfig` 中添加 `language` 字段：

```rust
// src-tauri/src/config.rs
pub struct AppConfig {
    // ... existing fields
    pub language: String,  // "zh-CN" | "en-US"
}

impl Default for AppConfig {
    fn default() -> Self {
        Self {
            // ...
            language: "zh-CN".to_string(),
        }
    }
}
```

### 4. 在组件中使用

```vue
<template>
  <div>
    <button>{{ $t('toolbar.commit') }}</button>
    <p>{{ $t('common.loading') }}</p>
  </div>
</template>

<script setup lang="ts">
import { useI18n } from 'vue-i18n';
const { t } = useI18n();

console.log(t('errors.svnNotFound'));
</script>
```

## 动态语言切换

设置页面添加语言下拉框：

```vue
<template>
  <select v-model="languageStore.currentLocale" @change="onLocaleChange">
    <option value="zh-CN">简体中文</option>
    <option value="en-US">English</option>
  </select>
</template>

<script setup>
const languageStore = useLanguageStore();
const onLocaleChange = () => {
  languageStore.setLocale(languageStore.currentLocale);
};
</script>
```

## 后端错误消息本地化

后端返回错误码，前端根据错误码查找本地化消息。不推荐后端返回本地化字符串，以保持后端语言无关。

```typescript
// 前端错误处理
function handleError(errorCode: string) {
  const key = `errors.${errorCode}`;
  const message = t(key);
  toast.error(message);
}
```
