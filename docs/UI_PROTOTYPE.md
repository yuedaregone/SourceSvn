## 本地修改视图 (LocalChangesView) - 整合提交对话框

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [✔ 全选] 已选 3 个文件                                  [拉取] [提交] [刷新] │
├───────────────────────────────┬─────────────────────────────────────────────┤
│ 文件列表（左侧上方）            │ 差异对比（右侧，默认不显示）                  │
│ ┌─────────────────────────────┐│ ┌─────────────────────────────────────────┐│
│ │ ☑  M   src/main.rs          ││ │                                         ││
│ │ ☑  A   src/new_feature.rs   ││ │  (选择文件后显示差异)                    ││
│ │ ☐  D   old_file.txt         ││ │                                         ││
│ │ ☑  ?   untracked_log.txt    ││ └─────────────────────────────────────────┘│
│ └─────────────────────────────┘│                                           │
│                                 │                                           │
│ 提交信息（左侧下方）             │                                           │
│ ┌─────────────────────────────┐│                                           │
│ │ 添加新功能xxx，修复bug       ││                                           │
│ │                             ││                                           │
│ └─────────────────────────────┘│                                           │
│ [🤖 AI生成注释]     [取消] [提交]│                                           │
│                                 │                                           │
│ 统计: +15 / -3 行               │                                           │
└───────────────────────────────┴─────────────────────────────────────────────┘
```

**交互说明**：
1. 左侧上方：文件列表，勾选文件影响提交范围
2. 左侧下方：提交信息输入框 + 操作按钮（AI生成注释、取消、提交）
3. 右侧：差异对比区域，**默认不显示任何内容**
4. 选择左侧上方任一文件后，右侧立即显示该文件的差异对比
5. 无文件选中时，右侧为空（或显示"点击文件查看差异"占位）

## 交互说明

1. **页签栏**：
   - 单击页签切换仓库，双击关闭页签
   - 左侧齿轮按钮打开设置模态框
   - "+" 打开仓库对话框（检出或添加已有工作副本）

2. **图标栏**：
   - 图标垂直排列，当前选中项高亮
   - Hover 显示 tooltip（含视图名称和快捷键提示）

3. **工具栏**：
   - 按钮根据当前仓库状态启用/禁用
   - 拉取、提交、刷新分别为 svn update、打开提交对话框、刷新当前视图

4. **差异查看器**：
   - 从日志视图双击文件、本地修改视图点击预览差异时唤起
   - 模态框或右侧滑出面板（MVP 使用模态框简化）

5. **AI 审查**：
   - 日志视图详情区、提交对话框、差异查看器中均提供 AI 审查按钮
   - 审查结果在右侧滑出面板显示，支持流式输出

6. **本地修改视图**：
   - 左侧文件列表支持多选，差异区域实时显示当前选中文件的变更
   - 提交对话框不再独立弹出，整合在视图右侧/下方
   - 提交信息框始终可见，与文件列表同侧

## 响应式考量

- 最小窗口宽度: 800px
- 最小窗口高度: 600px
- 图标栏宽度固定 48px，不随窗口缩放
- 表格和树形组件支持横向滚动
